---
title: Quick Start
description: Get up and running with Billy in 2 minutes
---

## 1. Start Billy

```bash
billy
```

You'll see the Billy chat interface in your terminal.

## 2. Say hello

Just type a message and press **Enter**:

```
> Hey Billy, what can you help me with?
```

## 3. Try some commands

Type `/` to open the command picker and browse all available commands.

Or try these:

```
/model              ← see available models
/pull llama3.2      ← download a model
/memory             ← see what Billy remembers
/help               ← full command list
```

## 4. Let Billy remember things

Just tell Billy naturally:

```
> Remember that I'm building a Go web app using Fiber
> Save that I prefer short, direct answers
```

Billy stores these and includes them in every future conversation.

## 5. Resume a previous session

```
/history            ← browse past conversations
/resume 3           ← jump directly to conversation #3
```

## Keyboard shortcuts

| Key | Action |
|---|---|
| `Enter` | Send message |
| `↑ / ↓` | Navigate command picker |
| `Esc` | Dismiss command picker |
| `Ctrl+C` | Exit Billy |
