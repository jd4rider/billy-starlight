## Prerequisites

Billy needs [Ollama](https://ollama.com) to talk to AI models.

- **CLI installs** — install Ollama separately
- **Billy Desktop** — ships the desktop app and the `billy` CLI together, but Ollama still installs separately

:::note[Fast-moving releases]
Billy is shipping quickly. Expect occasional rough edges and some breaking changes between versions.
:::

## Quick Install

<Tabs>
  <TabItem label="Desktop (macOS/Linux)">
  ```bash
  curl -fsSL https://raw.githubusercontent.com/jd4rider/billy-wails/main/scripts/install.sh | bash
  ```
  Installs Billy Desktop plus the bundled `billy` CLI.
  </TabItem>

  <TabItem label="CLI (macOS/Linux)">
  ```bash
  curl -fsSL https://raw.githubusercontent.com/jd4rider/billy-app/main/scripts/install.sh | bash
  ```
  Then install Ollama separately at [ollama.com](https://ollama.com).
  </TabItem>

  <TabItem label="Homebrew (CLI)">
  ```bash
  brew tap jd4rider/billy
  brew install billy
  ```
  </TabItem>

  <TabItem label="Windows (Scoop CLI)">
  ```powershell
  scoop bucket add billy https://github.com/jd4rider/scoop-billy
  scoop install billy
  ```
  </TabItem>

  <TabItem label="Desktop downloads">
  - macOS `.pkg` / `.tar.gz`: [Billy Desktop releases](https://github.com/jd4rider/billy-wails/releases)
  - Windows `.zip`: [Billy Desktop releases](https://github.com/jd4rider/billy-wails/releases)
  - Linux CLI archives and packages: [Billy CLI releases](https://github.com/jd4rider/billy-app/releases)
  </TabItem>

  <TabItem label="Build from source">
  ```bash
  git clone https://github.com/jd4rider/billy-app.git
  cd billy-app
  go build -o billy ./cmd/billy
  ./billy
  ```
  Requires Go 1.24+.
  </TabItem>
</Tabs>

## Verify installation

```bash
billy --version
```

## Pull your first model

```bash
ollama pull mistral    # great all-rounder, ~4GB
# or
ollama pull llama3.2  # fast 3B model, ~2GB
```

Then run `billy` and start chatting.
