## Status

Billy is in **pre-alpha**. The core is working; we're expanding features and stabilising.

## ✅ Done

- [x] Interactive TUI (Bubble Tea)
- [x] Local Ollama backend
- [x] Conversation history (SQLite)
- [x] Memory system (natural language)
- [x] History session picker
- [x] Model list, switch & pull
- [x] Friendly error handling
- [x] Slim + Full (bundled Ollama) builds
- [x] Homebrew tap, Scoop bucket, .deb/.rpm packages
- [x] Command picker (type `/` for dropdown)

## 🔜 Coming soon

- [ ] Context compaction (`/compact`)

- [ ] Integration tests
- [ ] Groq backend
- [ ] Custom HTTP backend
- [ ] Billy.sh cloud SaaS backend
